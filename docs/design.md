# Make Your Life Better — 设计摘要

> 2026-09-23 经过 grilling 访谈确认。改动设计时先更新这份文档。

## 一、整体架构

- **定位**：浏览器里使用的提效工具集，**纯前端，数据不离开本机**
- **技术栈**：Vite + React 19 + TypeScript strict + Tailwind v4 + shadcn + tweakcn + React Router 7 + pnpm
- **结构**：单页应用（SPA），每个工具一个懒加载路由
  - `src/tools.registry.ts` 统一登记工具的元信息和路由
  - 首页是工具卡片网格，顶部导航可以切换工具
  - 共享能力放在 `src/shared/`：Worker 解析、IndexedDB 存储、上传组件
- **主题**：内置几套 tweakcn 预设，用户在设置里切换，选择存在 localStorage
  - 支持深色/浅色（跟随系统，也可以手动切换）
  - AG Grid 通过 Theming API 读同一组 CSS 变量
  - 差异、缺失、重复这几个语义色单独定义，只跟深浅色走，不跟用户主题走
- **部署和语言**：暂不考虑。默认打成纯静态产物，界面只做中文，文案集中管理

## 二、工具一：Excel 数据对比

### 输入

- 支持 xlsx、csv，**不支持 xls**；一次 2～3 个文件
- xlsx 用 SheetJS 0.20.3（从官方 CDN 的 tgz 安装，不用 npm 上的 0.18.5），csv 用 PapaParse，都在 Web Worker 里跑
- CSV 编码自动检测：先用严格 UTF-8 解码，失败就换 GB18030；也可以手动切换，并预览前几行
- 用户可以选 sheet、指定表头行，合并单元格自动向下填充

### 对比模型

- 按主键匹配（支持组合主键），再比较选中的字段
- 同名列自动配对，不同名的由用户手动映射
- **无基准宽表**：每行可以同时带多个标签，包括一致、有差异、某文件缺失
- 主键重复、主键为空的行单独归一类，不参与对比，但会列出来

### 值归一化

- 默认规则：去掉首尾空格；空值都算相等；数字按数值比较（"1.0" = 1）；日期统一成 YYYY-MM-DD
- 开关：忽略大小写、全角转半角、文本型数字保留前导零（默认开，也就是 "001" ≠ "1"）

### 操作流程

- 第一次使用走向导：① 上传 → ② 选 sheet 和表头行 → ③ 选主键、对比字段并做映射 → ④ 看结果
- 到了结果页，配置收进侧边抽屉，改完点"重新对比"

### 结果展示

- 用 AG Grid Community，只读
- 列按"文件为主、字段为次"分组；主键列、状态列固定在左边；每个文件分组里的字段顺序一致
- 差异单元格高亮，缺失的格子显示灰色"—"
- 顶部汇总条：全部一致 / 有差异 / 有缺失 / 主键重复 / 主键为空，点击可以筛选（一行可能同时属于多类）。默认只显示有差异的行
- 附带展示列：只展示，不参与比较
- 行详情抽屉：一行数据的"字段 × 文件"竖表
- "只显示有差异的列"开关
- 主键搜索框

### 导出

- 导出 xlsx，差异单元格带底色（导出时才懒加载 ExcelJS）
- 另外附一个"差异明细"长表 sheet：主键 / 字段 / 各文件的值
- 导出范围跟随当前筛选

### 本地存储（IndexedDB）

- 存原始文件、配置和解析后的列式数据；结果不存，打开任务时重新算
- 最多 10 个任务，超过 30 天自动清理
- 有历史任务列表，可以单个删除、一键清空，并显示占用空间
- 首页提示"数据只保存在本浏览器"
- 无痕模式或存储空间满了的时候，降级为不保存

### 边界情况

- 表头空列名自动命名为"列C"，重名列改成"姓名(2)"
- 空 sheet 在第 ② 步拦住
- 文件损坏或加了密码时，显示具体原因
- 内存不够时提示用户拆分文件
- 主键映射不全时，第 ③ 步不能继续

## 三、质量与性能

- 对比引擎写成纯函数，放在 Worker 里跑，用 Vitest 做单测，重点测值归一化
- 用生成的 10 万行测试文件跑 Playwright 冒烟测试
- 目标：3 个文件 × 10 万行 × 20 列，出结果 ≤ 5 秒；滚动保持 60fps；主线程上没有超过 100ms 的长任务

## 四、选型备忘

- 不用 Handsontable：7.0 之后只对非商业用途免费
- 不用 Glide Data Grid：正式版只支持到 React 18，支持 React 19 的版本还停在 alpha，维护也放缓了
